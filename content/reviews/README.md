# 客人评价

**一人一个文件。** 文件名用英文小写，不要空格。

| 想做什么 | 怎么做 |
|---|---|
| 改某条评价 | 打开对应 yaml 改文字 |
| 新增评价 | 复制任意一份，改文件名和字段后提交 |
| 删除评价 | 删掉对应 yaml 后提交 |
| 换客人照片 | jpg 放进 `public/reviews/`，路径写成 `reviews/文件名.jpg` |

`route` 只能填 `r1` / `r2` / `r3`。文件顶部 `src:` 标客人原话是中文还是英文；只改原文即可。

`photos` **只用** `reviews/...`（含 `.mp4`），不要填 `destinations/...`。每条评价的 `slug` 必须唯一（多条「匿名」请改成不同 slug）。

详见 [内容编辑指南](../README.md)。
