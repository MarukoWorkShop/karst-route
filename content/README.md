# 内容编辑指南（不需要写代码）

这个文件夹里的文件控制着网站上的文字内容 —— 线路名称、价格、费用说明等。
**改这里的文件 → 保存 → 网站约 1 分钟后自动更新**。不用改代码，也不用找技术人员。

---

## 怎么改（在网页上直接改，最简单）

1. 打开 <https://github.com/MarukoWorkShop/karst-route>
2. 点进 `content` → `routes` 文件夹
3. 点要改的文件（例如 `r3.yaml`）
4. 点右上角的铅笔图标 ✏️（Edit this file）
5. 改完之后，拉到页面**最底部**
6. 在 "Commit changes" 的两个框里随便填一句说明（例如「更新线路三价格」）
7. 点绿色的 **Commit changes** 按钮
8. 等约 1 分钟，刷新网站就能看到新内容

> 提示：手机上也能改，但屏幕小容易看错缩进，建议用电脑。

## 填写规则（重要，请一定看）

1. **中英文成对填写**
   每个字段下面都有 `en:`（英文）和 `zh:`（中文），两个都要填。
   只填一个的话，另一个会自动用程序里的旧内容顶上 —— 页面不会白屏，但显示的可能不是你要的。

2. **冒号后面必须空一格**
   ✅ `name:`（冒号后有空格）
   ❌ `name:`（冒号后直接跟内容）

3. **缩进只能用空格，不能用 Tab 键**
   同一层级的缩进要对齐。文件里现有的缩进就是正确示范，照着抄最稳。

4. **费用项只填英文 id，不要写中文**
   文件注释里列出了所有可选 id，照着填即可。

5. **不确定的地方先看灰色注释行**（以 `#` 开头），那里写了说明。

## 改错了怎么办

**网站不会崩。** 如果某个文件格式写错了，或者某个字段漏填了，
网站会自动使用程序里的默认内容，页面照常显示。

发现改错了，按上面的步骤再改一次、提交即可。

## 常见问题

**Q：改完多久能在网站上看到？**
A：提交后约 1 分钟。如果等了 3 分钟还没变，刷新页面时按 `Ctrl+F5`（Mac 用 `Cmd+Shift+R`）强制刷新。

**Q：我可以新增一条线路吗？**
A：暂时不行，需要技术人员先做好模板。请提需求。

**Q：图片怎么换？**
A：图片不在 `content` 文件夹里，请联系技术人员更换。

**Q：改的内容能撤销吗？**
A：能。在文件页面点右上角的 "History"（历史记录），找到之前的版本点 "Revert" 即可恢复。
